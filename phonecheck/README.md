# RemTeh PhoneCheck 0.2.1 preview

Android 8+; проверено в отдельном Android 15 SDK-эмуляторе. [APK и SHA-256](https://github.com/remteh-by/Device-Lab/releases/tag/v0.2.2).

Цветовые поля, мультитач, короткий сигнал через текущий аудиовыход, временная запись микрофона на 5 секунд и прослушивание, Vibrator API, доступные SensorManager-датчики, системная камера с миниатюрой, BatteryManager. Результат отмечает мастер: наблюдалось в тесте / есть замечание / не измерено / недоступно. Отказ в разрешении и отсутствие событий не отмечаются как успешный тест.

История хранит последние 20 сессий локально. Текущая сессия восстанавливается после перезапуска той же версии. Перед новой проверкой требуется сохранение; ошибка записи сохраняет текущие данные. Обновление debug 0.2.0 → 0.2.1 с тем же сертификатом проверено с сохранённой историей. История старой версии остаётся доступна, а новая версия начинает отдельную сессию.

Импорт: JSON `phone-intake schema 1` до 128 КБ. Строгий разбор ограничивает вложенность, строки, числа и число узлов; повторные поля и неизвестные статусы отклоняются. Импортированный отчёт используется отдельно для сравнения и не заменяет текущие наблюдения. Отличия устройства, Android, источника и версии показываются явно. Текст отчёта отображается обычным TextView. Экспорт использует системный выбор файла.

Нет INTERNET, контактов, SMS, звонков, общего хранилища, серийного номера или загрузки медиа. RECORD_AUDIO запрашивается по действию с объяснением. Временный звук удаляется при уходе; recorder/player/tone/sensors/vibrator освобождаются. Камера открывается системным Intent; её собственное приложение может сохранять снимок по своим правилам. PhoneCheck получает только миниатюру и не помещает её в отчёт. Батарея — показания Android, не измерение ёмкости или износа.

Ссылки шести способов поддержки и новых версий открывают внешний браузер по нажатию. Платёж выполняется на стороне выбранного сервиса; тестовая сборка не обрабатывает карточные данные и не проверяет оплату. Новый APK устанавливается штатным Android-установщиком; скрытой установки и обхода сертификатов нет.

Сборка: JDK 17, SDK 35, `./gradlew :app:assembleDebug :app:lintDebug`. APK предварительный, debug-подпись. Исходный release-ключ для будущего стабильного канала не подменяется debug-ключом.

Проверено: 18 проверок строгого JSON, lint, сборка, реальное обновление APK с историей, поворот с импортом, неизменность текущей сессии, отклонение повреждённого импорта, нулевой мультитач, отказ RECORD_AUDIO через Android callback, сбой записи и добровольное приглашение поддержки. SDK-данные синтетические. Физическая матрица остаётся: Android 8/12/15+, OEM-камеры без миниатюры, занятый микрофон, разные аудиовыходы, реальные касания, датчики, мотор, зарядка, TalkBack и питание. Автоматического аппаратного заключения нет.
