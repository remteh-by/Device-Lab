# RemTeh PhoneCheck 0.1.0 MVP

Локальный прототип приёмочной проверки Android 8+. Реализованы цветовые поля, мультитач, короткий аудиосигнал, запись и прослушивание микрофона, вибрация телефона, доступные датчики, запуск системной камеры с просмотром миниатюры, сведения BatteryManager, ручные результаты, история 20 сессий и JSON через системный выбор файла.

Камера запускается только по действию пользователя. RECORD_AUDIO запрашивается только для теста микрофона с объяснением; временная запись удаляется при уходе из Activity. SensorManager, ToneGenerator, MediaRecorder, MediaPlayer и Vibrator освобождаются/останавливаются при уходе. Нет разрешения INTERNET, контактов, SMS, звонков, общей памяти и автоматического сбора серийного номера. Камера может сохранять фото по собственным правилам, что объяснено перед запуском.

Отметку «работает в этом тесте» делает мастер. Недоступная функция, отказ в разрешении и неполученные данные не считаются успешным тестом. Заряд/температура/напряжение — показания Android, не измерение ёмкости или износа батареи. Короткий аудиосигнал идёт через текущий аудиомаршрут, не гарантированно через встроенный динамик. Камера возвращает миниатюру, не тест разрешения, фокуса и всех объективов.

## Сценарий

Новая сессия → выбор одного теста → объяснение / разрешение при необходимости → наблюдение мастера → отметка → комментарий → просмотр / экспорт. Для другого аппарата начните новую сессию. История локальная; автосохранение происходит при уходе. Сброс, перепрошивка и CRM не используются.

## Сборка и статус

JDK 17, SDK 35, Gradle 8.9 / AGP 8.7.3. Выполните ./gradlew :app:assembleDebug :app:lintDebug. APK является debug-прототипом, без обещания готового публичного релиза или нового сертификата для существующего продукта. Новая лицензия от имени владельца не назначалась.

Физическая приёмка отложена владельцем: Android 8/12/15, устройство без гироскопа/барометра, отказ RECORD_AUDIO, занятый микрофон, фоновый переход/поворот, системная камера без миниатюры, Bluetooth-аудио, несколько касаний, разные режимы зарядки и экспорт. Отдельно проверить экранные отступы на targetSdk 35 и TalkBack. Данные ОС не заменяют испытаний питания/аккумулятора лабораторным оборудованием.

Следующая итерация: полноценный импорт/сравнение, расширенный сценарий отдельных камер/каналов аудио и установочный релиз после физической приёмки. Текущий MVP не выдаётся за сертифицированный диагностический комплекс.
